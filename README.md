# WG45

Apartment Cleaning and Waste Cleaning for Sahadat, Nusrat, Marzan, Koushik and Ritesh.

A static website: no build step, backend, API key, or external hosting provider is required. Publish the repository root from the main branch with GitHub Pages. Every update pushed to main will be published automatically.

Cleaning duties rotate every Monday. Bio waste rotates every three days; plastics and paper rotate weekly. Each duty cycles through all five people. Dates and countdown deadlines follow Europe/Berlin, including daylight-saving changes.

Select a flatmate in the bottom bar to view their illustrated portrait, assigned tasks and countdowns. Select them again, use the close button, or press Escape to return.

Edit schedule.js for rotation rules, ui.js for interactions, and index.html for layout and styles. Portraits are in avatars/.
